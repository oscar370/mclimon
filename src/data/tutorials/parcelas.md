# Parcelas

## Acceso al Mundo de Parcelas

---

Para ingresar al mundo plano donde se encuentran las parcelas, utiliza el siguiente comando:

```
/warp parcelas
```

Este mundo está diseñado para construir y gestionar espacios privados de forma organizada.

## Obtener Parcelas

---

Para obtener una parcela aleatoria, escribe:

```
/plot auto
```

> ¡Solo puedes tener hasta 4 parcelas por usuario!

Si prefieres escoger una parcela en específico, entra dentro de ella y ejecuta:

```
/plot claim
```

## Gestionar Permisos

---

Para permitir que otro jugador acceda a tu parcela siempre, usa:

```
/plot trust [nombreJugador]
```

Otorgar acceso temporal (solo mientras estás en línea):

```
/plot add [nombreJugador]
```

Para eliminar los permisos de un jugador, ejecuta:

```
/plot remove [nombreJugador]
```

> Por defecto, solo tú puedes interactuar en tu parcela.

## Administrar Parcelas

---

Para identificar fácilmente una parcela, asigna un alias:

```
/plot alias [nombreParcela]
```

Si tienes parcelas adyacentes, puedes combinarlas en una sola área:

```
/plot merge [all/ubicaciónParcela]
```

Ejemplo para fusionar todas las parcelas adyacentes:

```
/plot merge all
```

> ¡Recuerda que las parcelas deben estar juntas para que la fusión funcione!

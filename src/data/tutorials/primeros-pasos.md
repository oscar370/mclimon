# Primeros Pasos

## Registro

---

Antes de comenzar a jugar, tendrás que registrarte en el servidor colocando lo siguiente en el chat:

```
/register [contraseña] [confirmarContraseña]
```

Este seria un ejemplo de un registro:

```
/register micontraseña123 micontraseña123
```

Una vez registrado, podrás entrar a jugar. La sesión se guarda, por lo que no tienes que iniciar sesión cada vez que entres al servidor.

## Kit Inicial

---

¡Puedes recibir un set de armadura, herramientas y comida para iniciar tu viaje! Solo tienes que colocar en el chat:

```
/kit inicio
```

Puedes recibir este kit cada tres horas, por si lo necesitas.

## Random Teleport

---

Estando en el mundo survival, puedes transportarte hacia lugares aleatorios con el siguiente comando:

```
/rtp
```

Tardará cinco segundos en llevarte a tu destino.
